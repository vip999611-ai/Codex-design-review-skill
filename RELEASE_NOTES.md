# Design Review Skill v1.0.0

## English

The first stable release of a read-only, evidence-graded Codex skill for expert visual design critique.

Highlights:

- Reviews posters, banners, brand and character visuals, presentations, data visualizations, UI, and design variants.
- Separates observations, professional inferences, and unknowns.
- Prioritizes issues from S0 blockers to S3 polish and validates supported weighted scores deterministically.
- Produces synchronized annotated issue images and low-fidelity optimization diagrams when suitable tools are available.
- Preserves source files and keeps Figma access read-only.

Install: download `design-review-v1.0.0.zip`, verify the accompanying SHA-256 file, and extract it into your personal Codex skills directory so the final path is `<skills-directory>/design-review/SKILL.md`.

## 中文

这是只读、分级证据驱动的 Codex 视觉设计专家评审 skill 的首个稳定版本。

主要能力：

- 支持海报、Banner、品牌与角色视觉、演示文稿、数据可视化、UI 和多方案比较。
- 明确区分观察事实、专业推断和未知信息。
- 按 S0 阻断问题到 S3 润色建议划分优先级，并确定性校验有证据支持的加权评分。
- 在工具允许时生成与书面问题同步的问题标注图及低保真优化结构示意。
- 不修改源文件，Figma 操作仅限只读。

安装：下载 `design-review-v1.0.0.zip`，验证配套 SHA-256 文件，然后解压到个人 Codex skills 目录，确保最终路径为 `<skills 目录>/design-review/SKILL.md`。
