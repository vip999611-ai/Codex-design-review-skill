# Multiple artifacts and series

## Compare variants

Hold goal, audience, channel, and scoring weights constant. For each variant identify:

- Strongest strategic advantage
- Largest risk
- Best-fit scenario
- Decisive evidence for recommendation

Before scoring, create an **identity anchor** for every variant using its exact filename/label plus 2–4 unmistakable visible traits, for example `03 — orange middle field, oversized English title, dark two-column product block`. Repeat the filename and at least one anchor trait in every recommendation. Never refer to variants only as "the first/second" or "the simple/dense one".

Run a recommendation consistency check:

1. State the channel's primary job: stop attention, establish brand, explain, compare, or enable purchase.
2. Match the recommended variant's anchored visible traits to that job.
3. State why the other anchored variant is weaker for that job.
4. Try to falsify the recommendation by checking whether the explanation accidentally describes the other file.
5. If the visual evidence supports different channels, provide a channel matrix instead of one universal winner.

Use a shared comparison table. If scores differ by fewer than 3 points, call them effectively tied and choose by the most important design-contract criterion.

## Review a series

Separate:

- Invariants: logo, grid, type roles, palette roles, recurring motif, illustration/icon grammar, metadata, CTA
- Controlled variables: subject, headline, campaign color, image crop, data, page function
- Accidental drift: margins, weights, icon volume, radius, alignment, effects, terminology

Score both individual quality and series coherence. Do not average away one severe outlier.

## Review a deck

Evaluate at three levels:

1. Deck narrative: setup, progression, evidence, conclusion, action
2. Slide function: one takeaway and appropriate evidence
3. Craft system: master, grid, type, charts, imagery, sources, page furniture

Use representative sampling only when the deck is very long and disclose sampled pages. Always inspect opening, agenda/structure, at least one dense slide, one data slide, one section divider, and closing/action slide when present.
