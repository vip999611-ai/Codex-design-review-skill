# Curated sources and provenance

Last reviewed: 2026-08-12.

Use sources to support judgment, not replace the design contract. Prefer level A for requirements, level B for professional principles, and level C for optional techniques. Cite direct pages near high-risk or mandatory claims. Browse on demand when a platform may have changed, a specialized domain is uncovered, or the user asks for current sources.

## Evidence levels

- **A — governing/official:** user-supplied project/brand rules, applicable regulation, WCAG, or platform-owner requirements.
- **B — institutional/professional:** mature design systems, professional bodies, established research/education sources.
- **C — practitioner heuristic:** articles, tutorials, case analyses, and reviewer experience.

Never create an S0/S1 solely from a C-level source.

## IP and character-source rule

Treat the user-provided character bible, model sheet, turnaround, expression sheet, material guide, and canonical asset package as level A for that project. Without those artifacts, silhouette, shape language, pose readability, and appeal remain level C heuristics. Do not claim off-model proportion, unauthorized shape change, or brand/IP noncompliance without canonical evidence.

## Source maintenance

- Record title, publisher/author, direct URL, topic, level, applicable routes, key use, and verification date.
- Paraphrase principles; do not copy full articles, long passages, or source images into the skill.
- Recheck time-sensitive platform requirements before using them as A-level findings.
- Demote inaccessible, unverifiable, or outdated material instead of repeating it as fact.
- Apply conflict priority: law/regulation and non-waivable mandatory requirement > project/brand rule > platform/medium requirement > B-level professional principle > C-level practitioner technique. If a project rule conflicts with a mandatory requirement, surface the conflict and require the project rule to be corrected.
